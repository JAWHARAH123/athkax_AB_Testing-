# دورة التجارب واختباراتA/B والاستدلال السببي

## المشروع
 هل عرض تقييمات المستخدمين بجانب المنتجات يزيد معدل الشراء؟
 
## الوصف
متجر إلكتروني يدرس عرض متوسط التقييم (النجوم) وعدد المراجعات بجانب كل منتج في قائمة المنتجات ونتائج البحث. تساعد التجربة على قرار: هل نطلق هذا العرض لكل المستخدمين؟
 
## السؤال والفرضية
- القرار: هل نعرض التقييمات بجانب المنتجات لكل المستخدمين؟
- الفرضية: إذا عرضنا التقييمات بجانب المنتجات، فسوف ترتفع نسبة الشراء، لأن التقييمات تعطي المشتري ثقة ودليلًا اجتماعيًا وتقلل تردده.
## التصميم
- وحدة العشوأة: المستخدم، بنسبة 50/50 (A بدون تقييمات، B مع التقييمات).
- المقياس الرئيسي: نسبة المستخدمين الذين أكملوا طلبًا.
- مقاييس الحماية: الربح لكل مستخدم، ونسبة الإلغاء، والتواصل مع الدعم.
- حجم العينة والمدة: 25,737 مستخدم لكل مجموعة (خط أساس 6%، وأصغر أثر يهمنا 0.6 نقطة، α=0.05، قوة 80%)، والمدة 14 يومًا.
## النتائج والتوصية
- الأثر الرئيسي وفترة الثقة: نسبة الشراء من 5.73% إلى 6.73%، أي +1.00 نقطة (فترة الثقة 95%: من 0.64 إلى 1.36). مع CUPED: +0.99 (من 0.63 إلى 1.34). فحص نسبة التوزيع سليم (p=0.15)، وكل مقاييس الحماية سليمة.
- التوصية: نطلق الميزة تدريجيًا مع مجموعة holdout لمدة شهر للتأكد من استمرار الأثر.
